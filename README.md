# Kerentanan-banjir-Kab.-Cilacap
Informasi dalam WebGIS ini divisualisasikan dalam bentuk peta tematik sehingga kondisi kerentanan banjir pada setiap wilayah dapat diketahui secara lebih mudah. Tingkat kerentanan banjir diperoleh melalui pengolahan beberapa parameter yang berkaitan dengan kondisi fisik dan lingkungan wilayah.
